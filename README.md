# ⛏️ CraftLife

> **Minecraft-inspired RPG Habit Tracker Desktop App**  
> Turn your daily habits into quests, level up your character, collect pets, battle bosses, and build your productive life.

---

## 📌 About CraftLife

**CraftLife** is a gamified desktop productivity application built with **Python + PyQt6 + SQLite**, inspired by Minecraft-style RPG mechanics.

Instead of using a boring to-do app, CraftLife transforms your real-life progress into an adventure:

- Complete habits → gain **XP & Gold**
- Finish dailies and quests → **level up**
- Buy items from the shop
- Collect and upgrade pets
- Join guilds and fight bosses
- Track sports activities
- Manage personal economy
- Customize your character

Your real life becomes your game.

## 📦 Installation

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/CraftLife.git
cd CraftLife
```

---

### 2. Install Dependencies

```bash

```

---

### 3. Run App

```bash

```
